# packs/ro — Romanian

The reference language pack, extracted from [limba](../../upstream/map.md) — the workspace
mova was generalized from. Its tables, normalization map and dictionary adapter carry a
year of real classroom incidents (cited in the module docblocks), and its golden fixtures
were generated by running limba's own classifier, so this pack doubles as the
behavior-identity proof for the engine split and as the worked example every new pack is
authored against (`packs/_template/GENERATE.md`).

- **POS tables** — the tag grammar (`m/f/n` say noun, `v` says verb, `interog` question
  word…), the taught plural endings, the `a `-infinitive heuristic, the un/doi · o/două
  count articles.
- **Normalization** — dead-key look-alike folding (ǎ ş ţ ś ā → ă ș ț), NFC first. The
  list is open; the principle (input method is never a language error) governs.
- **Dictionary** — dexonline.ro, the Romanian dictionary. Gender, attested forms, and a
  human-checkable paradigm link per headword.
- **notes.md** — the raw Romanian reference material (error taxonomy, resource registry,
  materials sources, grammar system inventory) that a setup session mines when the
  learner's target is Romanian.
