The adjective copies its noun — U04, part 1.

e the ending that changes oa a change inside the stem m f n gender
.tohub — first thing inside .wrap, on every page, relative href (in work/visuals/: exactly index.html). A page without it is a dead end from a bookmark (limba, 2026-08-10).

.key — legend of the marks the page uses. Use when the page marks morphemes or genders. Skip marks the page never shows.

.card — one idea per card. Tables always sit in .card.scroll so they scroll inside the card, never the page.

b.mk / b.st — every inflection table marks the changing morpheme (b.mk) and any stem shift (b.st), marked segments lining up down the column so the pattern is visible without reading. Required when the pack declares inflection; a no-inflection pack's pages carry neither token.

.l2 — every target-language string. .l1 — support-language contrasts. Never colour a full sentence of meta prose.

③ Gender colouring

m un prieten · f o casă · n un scaun

.tag.g-<label> — one class and one token pair per gender the pack declares (ro: m f n). Use wherever a noun's gender is a fact the learner needs. Never invent labels the pack does not declare — visualcheck fails the page. Zero-gender packs drop the layer entirely.

④ Callouts

The point. The one insight the page exists for — at most one or two per page.
The carry-away rule, stated once, in one sentence.
The trap. What will catch the learner, and why.
The concept maps directly. A support-language parallel the learner already holds.
.lede (accent) · .rule (green) · .warn (red) · .anchor (support-language blue). Four voices, fixed meanings. Don't repurpose a colour for emphasis — the learner reads these borders as semantics, and consistency across months of pages is the product.

⑤ Worked example, counter chip, inline code

un frate bun → doi frați buni

4 forms — plural noun takes -i, so the adjective takes -i too. Cited as work/visuals/…acord.html.

.big — a full worked example the learner should read as one line. .cnt — a small counted fact (number of forms, of classes). code — repo paths and literal fragments only, never target-language words.

⑥ Guided attempt (.rev/.ans) — live

1. o stradă + curat — say the phrase, then reveal
o stradă curată — feminine singular, so -ă; and the adjective goes after the noun.
.rev/.ans — always 1:1 (visualcheck counts them). Concealed answers live on pages, not in chat — chat renders <details> as raw tags (limba convention). Use for beat-⑦ guided attempts whose answers appear nowhere else on the page. Not for word lists — those get the two-layer surface below.

"Nowhere else" is checked, not promised: visualcheck runs scripts/leakcheck.mjs over the page and fails on any HIGH finding. Don't print the promise to the learner — one generated page printed it above three items that leaked 3 of 3 (2026-08-15). An item whose answer sits in a table above is a worked example wearing an attempt's clothes; ask it over a novel word instead.

⑦ Audio: authored placeholder → embedded row

You author only this:

<div class="tts" data-text="un frate, doi frați"
     data-en="brother — singular, then plural"></div>

node scripts/tts-embed.mjs <file> turns it into this (static specimen — real buttons exist only after embedding):

un frate, doi frați
brother — singular, then plural
Audio lives in the row it voices — a button in the item's own row, never a parallel list duplicating a table (limba learner, 2026-08-10: "why is there a need to have two tables?"). A standalone stack is right only where the page prints nothing to attach to.

Never author the player script. tts-embed.mjs appends it once. A hand-copied second player gives every button two handlers that cancel each other — every clip valid, total silence (limba, 2026-08-12).

.vocab — the two-layer reveal: a page-wide mode filter (browse / L2→L1 / L1→L2) plus per-row reveal on click. Everything that names the answer conceals with it — translation, gender, plural, the note (a mode hiding only one row type leaks the rest — limba u01-deck defect, 2026-08-10).

Required on every drill surface and every teach-page word list — a table that can only be read is a table the learner re-drills somewhere else. On real pages each row also carries two clips (prompt alone / full pair) swapped by state, so audio never out-speaks the concealment; playback stops on every state change. Scope to a wrapper, never <body>.

Word list or paradigm? visualcheck now fails an open table whose rows pair one target form with its translation — that is a word list, and it belongs here. The paradigm table in ② is the other thing and stays open: its rows carry the same word in several forms, so the row teaches a pattern rather than testing a meaning. The German page opened with a ten-row open copy of its own drill list, which is what handed away every guided-attempt answer above it (2026-08-15).

⑨ Section divider

.stripe — the one divider, between the teach half and the drill half of a page. Don't multiply dividers; numbered h2 sections already pace the page.

⑩ Verification: the marker and the source note

m perete · pl. pereți? — wall

Sources. Genders and plurals verified via the pack's dictionary adapter (dexonline), 2026-08-15. Forms carrying ? are unverified — the agent's word, not a source's.

Unverified. This pack ships no dictionary adapter, so no fact on this page is source-attested: every form is the agent's word until a tutor confirms it. The ? marks are the list to hand the tutor.

.unv — the ? of docs/mechanics/verification.md, sitting on the form it doubts, inside the cell that carries it. Same marker as the ledger's, so one convention covers both. Use on any form a source has not attested.

.src — the page's verification trail, at the foot: what attested these facts and when, exactly as a ledger trail reads. A page asserting language facts carries a marker or a note; visualcheck fails one carrying neither. Keep one of the two notes shown — the second is the null-adapter banner, and a pack with no dictionary must carry it, because state 1 is unreachable there and the marker is the only safety left. Two first generated pages asserted ~60 and ten facts with neither (2026-08-15).
