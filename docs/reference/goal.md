# Goal contract

> What "done" means for this learner, and the tie-breaker for every scope question.
> Generated at setup, 2026-09-12.

## The spec

**The scenario list is the spec.** 5 scenarios, in the learner's words — each with the
probe that decides whether it is owned:

| # | Scenario (learner's words) | Probe — a pass looks like | Skills |
| --- | --- | --- | --- |
| 1 | Читать техническую документацию по дизайн-системам и UI-фреймворкам (Reading technical documentation for design systems and UI frameworks) | Read one unfamiliar design-system doc page (e.g. a component's usage guidelines) cold and correctly answer 3 concrete questions about it, no dictionary needed for the gist | R |
| 2 | Читать статьи по UX/UI (Reading UX/UI articles) | Read one short UX/UI article (e.g. a Nielsen Norman Group piece) and summarize its main argument in 2-3 sentences, unassisted | R |
| 3 | Писать сообщения в рабочих чатах (Slack и т.п.) (Writing messages in work chats like Slack) | Write a 3-5 sentence work-chat message (status update, question to a colleague, or async design feedback) that a native-English colleague would find clear and appropriately casual, no translation help | W |
| 4 | Понимать английский на слух на созвонах (Understanding spoken English on work calls) — secondary/lower priority | Listen to a short (1-2 min) recorded work-call excerpt and correctly extract the 2-3 key points, one listen, no transcript | L |
| 5 | Уверенно писать и запоминать написание слов (Confidently writing and remembering word spelling) — learner's stated weak point | Write out a set of 15 previously-studied words from dictation/memory with no more than 1-2 spelling errors | W |

Every session activity must serve at least one scenario; work that serves none is scope
creep, however enriching. An eleventh scenario is the **next** goal contract — renew via
the review verb, don't accrete.

**Target volume**: ~300–500 ledger items to carry these 5 scenarios `(assumed at setup —
recalibrate at review)`. Derived from the scenarios' own domains: the vocabulary and
structural patterns a working product designer needs to read design-system docs and UX
articles and to write clearly in work chat is a few hundred items, not a general-English
syllabus — reading and writing scenarios (1, 2, 3, 5) drive most of it; the listening
scenario (4) rides the same vocabulary rather than adding its own.

## Deadline

**This goal has no deadline, and that is a feature, not a gap.** The review verb
therefore measures **volume and streak — scenarios passed against the list, sessions held
against the 3-4-blocks/week budget, ledger growth against the target volume above — never
pace-vs-date.** No session may invent a date to motivate with; urgency theater against a
fictional deadline is how no-deadline instances rot.

## Assessment

A **mock** is a **scenario run**: one scenario from the table simulated end-to-end,
unrehearsed — the agent plays the counterpart (the documentation page, the Slack thread,
the call recording) — scored **pass / assisted / fail** per the scenario's probe, frozen
as a snapshot with its "Not exercised:" list. A scenario counts **owned** after two cold
passes on separate days. Runs happen at phase gates and whenever the learner asks to
"test me".

**The verb that runs it:** `mock` — `focus: full` keeps mock active in this instance, so
the scenario runs ride their own verb rather than a substitute carrier. The instrument
never changes with the verb; only who carries it does.

## Non-goals

- Completeness — grammar and vocabulary enter only when a scenario needs them; a
  syllabus-shaped detour is scope creep here by definition.
- Spoken production (speaking practice) — never named as a goal in the interview; this
  instance does not build toward it, and no speaking scenario or section exists.
- Exam-format or certified-level English — this is a functional, scenario-driven goal,
  not a credential.
- General conversational fluency outside the work-chat and documentation registers named
  above — a scenario in a register the list doesn't name is the next goal contract, not
  scope creep to absorb here.
