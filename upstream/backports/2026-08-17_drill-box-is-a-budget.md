# `session_format.md` states the drill's 10–15′ bare, while the drill skill calls it a constraint

**Owed to limba.** Small — one line — but it is the line that leaks the number outward.

## The inconsistency

`.claude/skills/limba-drill/SKILL.md` § The size rule already says it plainly: **"The time box
is a constraint, not a description."** It then tells the agent to state an item count against an
agreed budget, and names the 56-slot drill that ran under a "10–15′" heading.

`docs/mechanics/session_format.md:29` still reads *"The drill variant (10–15′) is parts 1 + 3
only…"* — the figure presented bare, with no marker and no pointer to the size rule that governs
it. A session reading the mechanics file rather than the skill gets the number as a fact, and
PORT-016 already established that limba's own measured drills ran 15′, 36′ and 55′ under it.

## What mova did

mova 0.14.1 marked the number where it appears: the box is *a budget to size the set against,
never a prediction*, with the 3.7× overrun and the decision not to re-fit moved to
`docs/mechanics/why/session_format.md`. It also stopped four learner-facing surfaces from quoting
the figure as fact — those have no limba equivalent, since limba has no learner-facing guide.

## What is left to limba

**Whether to re-fit rather than re-frame.** PORT-016 judged three data points enough to stop
quoting the number but not enough to replace it, and handed the re-fit to `/limba-review` with
PORT-007's block model as the starting point. If enough sessions have accumulated since, the
right move upstream may be the re-fit mova cannot do — mova has taught nobody and has no data of
its own. Re-framing the line is the floor, not the recommendation.

Also open, and mova took no view: whether the **per-part boxes** of the full lesson (~10′ / ~30′
/ ~10′ / ~15′ / ~5′) deserve the same treatment. They carry the file header's blanket *default
(measured on limba's learner)* marker, and unlike the drill's box nothing on record contradicts
them — but nothing confirms them either, and the one lesson with a recorded duration straddled
three calendar days.
